# Power curve

Power curve

## Usage

``` r
# S3 method for class 'ilm_power'
plot(x, target = 0.8, ...)
```

## Arguments

- x:

  An
  [`ilm_power()`](https://huttoncp.github.io/illume/reference/ilm_power.md)
  result.

- target:

  Draw a line at this power.

- ...:

  Passed to the plotting function.

## Value

`x`, invisibly.
